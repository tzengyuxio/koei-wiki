# 三國志曹操傳

《三國志曹操傳》是光榮於 1998 年推出的 Windows 戰棋角色扮演遊戲，英傑傳系列第五作。以曹操為主角，從討伐黃巾開始，依對話選擇分出多條路線與結局，裝備也會隨使用次數成長。
